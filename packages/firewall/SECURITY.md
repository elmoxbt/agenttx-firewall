# Security

AgentTx Firewall is a security tool that has not been audited. Do not rely on it as your only control: use a dedicated agent wallet with a small balance, allowlists, and human review for large amounts.

Report vulnerabilities privately to the maintainers (add your contact / GitHub security advisory link here). Bypasses of the checks — a transaction that moves funds or grants authority yet receives `ALLOW` — are the most valuable reports. Please include a serialized transaction and the policy used.
